Croptic — Computer Vision Engineer, Osnabrück

Croptic develops camera systems that detect weeds and crop diseases on agricultural machines in real time.

Responsibilities
- Train and evaluate image classification and segmentation models for field imagery.
- Build data pipelines for large labelled image datasets, including data quality checks.
- Implement models in PyTorch and optimise them for edge deployment (TensorRT, NVIDIA Jetson).
- Work with agronomists and hardware engineers to validate models in the field.

Requirements
- Experience with image classification and segmentation using deep learning.
- Strong Python and OpenCV.
- Experience with PyTorch.
- Experience preparing and cleaning large image datasets.
- Interest in agriculture.

Nice to have: ROS 2, edge deployment on NVIDIA Jetson.
