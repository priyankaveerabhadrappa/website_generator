Freshroute — Data Engineer, Munich or remote (Germany)

Freshroute optimises delivery routes for grocery retailers. Our analytics platform turns telematics and order data into routing decisions.

Your tasks
- Build batch and streaming pipelines with Apache Spark and Python.
- Orchestrate workflows in Apache Airflow.
- Model data in our Snowflake warehouse using dbt.
- Ensure data quality with automated tests and monitoring.
- Support data scientists with clean, well-documented datasets.

Your profile
- Experience building production data pipelines with Spark.
- Hands-on experience with Airflow and dbt.
- Strong SQL and Python.
- Understanding of data modelling (star schema, slowly changing dimensions).
- Experience with a cloud data warehouse (Snowflake, BigQuery or Redshift).

Nice to have: Kafka, data quality tooling such as Great Expectations.
